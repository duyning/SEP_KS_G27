HOST MAIN USE CASE DIAGRAM
Source review date: 2026-11-25

One editable draw.io page; 11 grouped user goals. Numbers are presentation order, not UML control flow.
Applicant and Room Host are separate roles. A successful combined onboarding grants ROOM_HOST.
A property change or a viewing request is not a mandatory step in starting every tenancy.
Contracts are optional. Bills may precede utility finalization; a supplemental utilities bill is supported.
No include/extend relation is asserted merely because one screen follows another.
