# 🏠 HL_RCS

**Platform Connecting the Rental Community and Supporting Services in Hoa Lac**

HL_RCS is a web and mobile platform designed to connect renters, room hosts, and local supporting service providers in the Hoa Lac area.

The platform aims to provide a centralized, transparent, and convenient environment for accommodation discovery and rental-related activities.

## 🛠️ Technology Stack

- **Frontend:** React, Android
- **Backend:** Java, Spring Boot
- **Database:** MySQL, Firebase
- **External Services:** Google OAuth 2.0, Google Maps, Gemini API
- **Deployment:** AWS

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd SEP_KS_G27
```

Configure the required database credentials and API keys before running the application.

> Do not commit passwords, API keys, or other sensitive credentials to the repository.
